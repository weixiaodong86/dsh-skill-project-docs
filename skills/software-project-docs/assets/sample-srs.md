## 用例说明

:::fill 每个一级功能按“功能描述—输入—处理规则—输出—异常与边界—验收标准”六段式描述。

:::example 功能描述：企业租户提交入驻申请，填写企业名称、统一社会信用代码、联系人等信息。
输入：企业基本信息、证照扫描件（PDF/JPG，单个不超过 10 MB）。
处理规则：统一社会信用代码校验 18 位；同一信用代码在租状态不可重复申请。
输出：生成申请单号，状态置为“待审批”。
异常与边界：证照模糊时允许重传，最多 3 次。
验收标准：审批通过后自动生成租户档案，数据在 5 秒内可查询。
:::
