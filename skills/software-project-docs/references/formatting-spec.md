# 全文档排版规范

本节是硬规范。构建库 `assets/docx_kit.py` 已按此实现，手写脚本时也必须遵守；需要调整版式时改构建库顶部常量，不要在单份文档里临时改字号。

## 1. 页面与分节

| 项 | 规范 |
|---|---|
| 纸张 | A4，210 × 297 mm |
| 页边距 | 上 2.54 cm、下 2.54 cm、左 3.0 cm、右 2.5 cm（正文宽 15.5 cm） |
| 分节 | 三节：①封面（无页眉页脚）②前置部分（修订记录＋目录，罗马数字页码）③正文（阿拉伯数字，从 1 起） |
| 装订线 | 不设置；需要时统一加在左侧 0.5 cm 并在页面上说明 |

## 2. 封面

自上而下：

1. 右上角：密级（黑体 10.5 pt，右对齐）；
2. 项目名称（黑体二号 22 pt，居中，加粗）；
3. 文档名称（黑体一号 26 pt，居中，加粗，上下各留 12 pt）；
4. 文档编号、版本号（宋体小四，居中，两行）；
5. 签署表：无框线四列"身份／姓名／签字／日期"，行高不小于 0.6 cm，宋体小四；
6. 编制单位与日期（宋体小四，居中）。

封面只放以上要素，不放目录、不放正文摘要。

## 3. 页眉与页码

| 项 | 规范 |
|---|---|
| 页眉 | 左侧"项目名称 + 文档名称"，右侧"文档编号 + 版本号"，宋体小五 9 pt，下框线 0.75 pt |
| 页脚 | 居中"第 X 页 共 Y 页"，宋体小五 9 pt，X/Y 为域（`PAGE`／`NUMPAGES`） |
| 封面 | 无页眉页脚 |
| 前置部分 | 页眉同正文；页码用罗马数字（`lowerRoman`），从 Ⅰ 起 |
| 正文 | 页眉同正文；页码阿拉伯数字，从 1 重新起编 |

页眉中的版本号必须与封面、修订记录表、文件名一致。

## 4. 标题层级

| 级别 | 字体 | 字号 | 对齐 | 段前／段后 | 行距 | 编号示例 |
|---|---|---|---|---|---|---|
| 一级 | 黑体 | 三号 16 pt，加粗 | 左对齐 | 18 / 12 pt | 1.25 倍 | `1 引言` |
| 二级 | 黑体 | 四号 14 pt，加粗 | 左对齐 | 12 / 6 pt | 1.25 倍 | `1.1 编写目的` |
| 三级 | 黑体 | 小四 12 pt，加粗 | 左对齐 | 6 / 6 pt | 1.25 倍 | `1.1.1 业务背景` |
| 四级 | 黑体 | 小四 12 pt | 左对齐 | 6 / 3 pt | 1.25 倍 | `(1) …` |

- 标题与后续段落同页（`keep with next`）；标题不缩进、不加首行缩进。
- 编号与标题文字之间空一个半角空格，编号后不加顿号或点号。
- 最多到三级；需要第四层时改用"（1）"式条目标题，不新增标题级别。

## 5. 正文

| 项 | 规范 |
|---|---|
| 中文 | 宋体，小四 12 pt |
| 西文／数字 | Times New Roman，小四 12 pt |
| 段落 | 首行缩进 2 字符（`firstLineChars=200`），两端对齐，行距 1.5 倍，段前段后 0 |
| 段间距 | 段与段之间不加空行；需要分开时用标题或表格 |
| 强调 | 仅用加粗；不使用颜色、下划线、斜体（斜体保留给填写说明与示例） |
| 标点 | 中文全角标点；数字与英文用半角；中英文之间不强制加空格，但全文一致 |

## 6. 列表

| 类型 | 写法 | 规范 |
|---|---|---|
| 无序 | `- 条目` | 前缀 `●`，悬挂缩进 0.74 cm，宋体小四 |
| 有序 | `1. 条目` | 前缀"（1）"，悬挂缩进 0.74 cm，宋体小四 |

同一条目不超过 3 行；超过时改为"条目 + 分号并列"的正文段落。

## 7. 表格

| 元素 | 规范 |
|---|---|
| 表题 | 位于表格**上方**，居中，黑体五号 10.5 pt 加粗，格式`表{章}-{序} 表名`，与表格同页 |
| 表体 | 宋体小五 9 pt，单倍行距，段前段后 1 pt |
| 表头 | 加粗、居中、浅灰底纹（`F2F2F2`），跨页自动重复 |
| 框线 | 全框线 0.5 pt 单线，黑色；不设斜线表头 |
| 行高 | 最小 0.62 cm，内容垂直居中 |
| 列宽 | 按内容分配，合计等于 15.5 cm；用 `表: 名称 || 比例,比例` 指定 |
| 对齐 | 表头居中；短内容（≤16 字）居中，长文本左对齐 |
| 数字 | 右对齐或统一居中；同列小数位一致 |
| 空表 | 不允许交付只有表头的表；先给 `【待确认】` 行 |

单元格内不换行堆叠多段；确需多段时用"①②③"编号在同一单元格内连续书写。

## 8. 图

| 元素 | 规范 |
|---|---|
| 位置 | 紧随首次引用它的段落之后，居中，与上下文各留 6 pt |
| 宽度 | 不超过 14.5 cm；按内容比例缩放，不拉伸变形 |
| 图题 | 位于图**下方**，居中，黑体五号加粗，格式`图{章}-{序} 图名` |
| 分辨率 | 不低于 150 dpi；不使用截图压缩痕迹明显的图片 |
| 缺失 | 保留图题并写`［图片缺失：说明］`，提示用户补图后重建 |

## 9. 填写说明与示例（仅模板模式）

| 元素 | 规范 |
|---|---|
| 填写说明 | 楷体小四 12 pt，**斜体**，灰色 `595959`，前缀`【填写说明】`，首行缩进 2 字符 |
| 示例 | 楷体小四 12 pt，**斜体**，灰色 `595959`，首段前缀`示例：` |
| 位置 | 紧跟所属章节标题之后，先说明后示例 |
| 内容 | 说明写"填什么 + 粒度 + 依据"；示例必须与本章上下文自洽，不写"此处填写…"这类空话 |

正式模式不出现填写说明与示例；模板模式不允许整章只有说明没有示例（除非该章确实无示例可给，需在说明中注明"本章无需示例"）。

## 10. 注解

`:::note` 渲染为宋体五号 10.5 pt，前缀`注：`，首行缩进 2 字符，用于解释表格口径、数据来源、适用范围。一份文档不超过 5 处。

## 11. 编号规则

| 对象 | 规则 | 示例 |
|---|---|---|
| 章节 | 一级 `1`，二级 `1.1`，三级 `1.1.1`；由构建库自动生成 | `3.2 用例说明` |
| 表 | 按章编号 `表{章}-{序}`，每章从 1 起 | `表3-1` |
| 图 | 按章编号 `图{章}-{序}`，每章从 1 起 | `图2-1` |
| 附录 | 一级标题写`附录 A 名称`，不参与章节编号；表、图编号用附录字母 | `表A-1`、`图B-2` |
| 需求 | `FR-001`（功能）、`NFR-001`（非功能）；测试用例 `TC-001`；缺陷 `BUG-001` | — |
| 文档 | `{项目编号}-{文档代码}`，版本`V{major}.{minor}` | `YQ-2026-001-REQ-SRS V1.0` |

编号一旦发布不得复用；删除内容后保留空号，不重排。

## 12. 目录与修订记录

- **修订记录**：前置部分第一页，标题"修 订 记 录"（黑体三号居中），表格五列"版本号／日期／修订人／修订说明／审核人"，表头加粗底纹。首次发布也必须有记录行。
- **目录**：修订记录之后另起一页，标题"目 录"（黑体三号居中），自动目录域，收录 1–3 级标题，显示页码，点线前导符。
- 目录域随文档打开自动更新；交付前确认目录已生成，未生成时在 Word/WPS 中全选后按 F9 更新。

## 14. 字体可获得性

正文用宋体、标题用黑体、说明用楷体，均为 Windows 与 WPS 常备字体。在 macOS 上同名映射为 Songti SC / Heiti SC / Kaiti SC，不改生成代码；不得改用"微软雅黑""等线"等非规范字体。

## 15. 与构建库常量的对应

| 规范项 | `docx_kit.py` 常量 |
|---|---|
| 页面与页边距 | `PAGE` |
| 正文宽 | `CONTENT_WIDTH_CM = 15.5` |
| 字体 | `FONT_BODY`、`FONT_HEAD`、`FONT_KAI`、`FONT_LATIN` |
| 字号 | `SIZE_BODY/H1/H2/H3/CAPTION/TABLE/NOTE/HDR` |
| 行距 | `LINE_SPACING = 1.5` |
| 表格底纹 | `COLOR_HEADER_FILL = "F2F2F2"` |
| 说明灰度 | `COLOR_ANNOTATION = "595959"` |

## 16. 交付前视觉确认

结构自检通过后，抽查三处：封面是否单页、目录是否已生成、跨页表格表头是否重复。发现版式偏差时改构建库，不逐份手修。
